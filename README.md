# Ironvale — Next.js recreation

Includes the original construction animation and supporting React sections, plus a reconstructed homepage and shared header/footer.

## Setup
Install Node.js 20.9 or newer.
Run `npm install`, then `npm run dev`. Open http://localhost:3000.
For production run `npm run build`, then `npm start`.

## Scope and limitations
This is a source-based recreation, not an official Framer export. The original animation logic has been retained and Framer editor controls removed. Canvas layouts were converted to HTML/CSS; responsive layout and some icon/image treatments may need refinement. Only the current homepage is included. Links to other main pages have been redirected to relevant homepage sections. Photos remain externally hosted. No form delivery backend is included. Replace demo contact details before launch.

The package has not been compiled or browser-tested in this environment. Review on desktop and phone before deployment.
